# cod-stats

Call of Duty のチーム戦績管理ダッシュボード。スクリム・大会の試合結果と個人スタッツを記録・管理する内製 Web ツール。

## 機能

- **戦績管理** — Hardpoint / Search & Destroy / Overload の試合結果を記録
- **個人スタッツ** — キル/デス/ダメージ、モード固有指標（Hill 占拠時間・プラント数・ゴール数など）
- **チームサマリー** — 勝率・KD レシオ・直近の試合結果を一覧表示
- **対戦相手管理** — 対戦相手チームのマスタ管理と対戦成績サマリー
- **認証** — Supabase Auth によるメール/パスワードログイン、チーム単位のデータ分離

## 技術スタック

| 項目 | 技術 |
|---|---|
| フレームワーク | Next.js 16（App Router） |
| UI | React 19 + Tailwind CSS v4 + shadcn/ui |
| データベース / 認証 | Supabase（PostgreSQL + RLS） |
| デプロイ | Vercel |

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 環境変数の設定

`.env.local` を作成し、Supabase の接続情報を設定する。

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### 3. 開発サーバーの起動

```bash
npm run dev
```

[http://localhost:3000](http://localhost:3000) でアクセス可能。

## コマンド

```bash
npm run dev    # 開発サーバー起動（Turbopack）
npm run build  # プロダクションビルド
npm run lint   # ESLint 実行
```

## 画面構成と使い方

### ログイン (`/login`)

アプリの入口。ログインと新規登録の 2 つのモードを切り替えて使う。

- **ログイン** — メールアドレスとパスワードを入力してログイン
- **新規登録** — ユーザー名・メール・パスワードを入力し、「新しいチームを作成」または「既存チームに参加（チーム ID 入力）」を選んでアカウントを作成

### ダッシュボード (`/`)

チーム全体のパフォーマンスを俯瞰する画面。

- 総試合数・勝敗・勝率を表示
- モード別（Hardpoint / S&D / Overload）の勝率を表示
- メンバー別 K/D レシオ一覧（モード別内訳付き）
- 直近 5 試合の結果を表示
- 画面上部のドロップダウンで **対戦相手フィルタ** をかけると、特定チームとの成績のみに絞り込める

### 対戦一覧 (`/matches`)

記録済みのシリーズ（Bo3 / Bo5 などの一連の試合）を一覧表示する画面。

- 日付・対戦相手・種別（Scrim / 大会）・勝敗レコードを確認できる
- シリーズをクリックすると詳細画面へ遷移
- 管理者は編集・削除が可能

### 対戦登録 (`/matches/new`)

新しいシリーズを記録する画面。管理者のみ操作可能。

1. 対戦相手を選択
2. 種別（Scrim / 大会）を選択
3. 日付を設定
4. ゲームを追加し、各ゲームごとに以下を入力
   - モード（Hardpoint / S&D / Overload）
   - マップ
   - スコア（自チーム / 相手チーム）
   - 各プレイヤーのスタッツ（キル / デス / ダメージ + モード固有指標）
5. 必要に応じて YouTube URL・メモを入力
6. 保存

### 対戦詳細 (`/matches/[id]`)

シリーズ単位の詳細スタッツを確認する画面。

- シリーズ全体の勝敗サマリー
- プレイヤー別の総合 K/D（モード別内訳付き）
- 各ゲームの詳細スタッツ（自チーム vs 相手チームの並列表示）
- モード固有指標（HP: Hill 占拠時間 / S&D: プラント・デフューズ・FB・FD / OL: ゴール数）

### 対戦編集 (`/matches/[id]/edit`)

記録済みシリーズの内容を修正する画面。管理者のみ操作可能。対戦登録と同じフォーム構成で、既存データが入力済みの状態で表示される。

### 対戦相手管理 (`/opponents`)

対戦チームの一覧と、各チームとの通算成績を確認・管理する画面。

- チームごとのシリーズ戦績・ゲーム戦績・モード別勝率を表示
- チーム名をクリックすると対戦相手詳細画面へ遷移
- 管理者は対戦相手の追加・編集・削除と、相手チームのプレイヤー管理が可能

### 対戦相手詳細 (`/opponents/[id]`)

特定の対戦相手との Head-to-Head 成績を確認する画面。

- シリーズ勝率・ゲーム勝率のサマリー
- モード別の勝率テーブル
- 過去の対戦履歴（各シリーズの結果とスコア）

### プレイヤー管理 (`/players`)

チームメンバーの一覧画面。管理者はプレイヤーの追加・編集・削除が可能。

### メンバー別スタッツ (`/players/[id]`)

個人のパフォーマンスを確認する画面。

- 総合スタッツ（試合数・勝率・K/D・平均ダメージ）
- モード別スタッツ（試合数・勝率・K/D・平均キル数・平均ダメージ）
- モード固有指標の平均値（HP: 平均 Hill 時間 / S&D: 平均プラント数等 / OL: 平均ゴール数）

### 設定 (`/settings`)

チームの設定画面。3 つのセクションで構成される。

- **プロフィール** — アバター画像の変更・ユーザー名の変更
- **チーム管理** — チーム ID のコピー（新メンバー招待用）、メンバー一覧とロール管理（管理者のみ）
- **マップ管理** — モード別のマップ追加・編集・削除（管理者のみ）

### ロールについて

| ロール | 権限 |
|---|---|
| **admin**（管理者） | 全画面の閲覧 + 対戦登録・編集・削除、対戦相手管理、プレイヤー管理、マップ管理、メンバー管理 |
| **member**（メンバー） | 全画面の閲覧のみ |
